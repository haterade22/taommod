The user (haterade22 on GitHub) is both a game modder and web developer. They maintain the TAOM total conversion mod for Bannerlord and built a companion website to display mod data. They also work on LEVI-Achaea (a Mudlet combat system for Achaea MUD) in a separate project.

They are comfortable with TypeScript, Astro, XML data pipelines, and game engine mechanics (TaleWorlds damage physics). They use Claude Code extensively with plugins, MCP servers (Serena, Context7), and agent teams.
